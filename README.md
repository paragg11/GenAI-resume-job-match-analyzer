# GenAI-Powered Resume & Job Match Analyzer

## Overview

An AI-powered application that analyzes resumes against
job descriptions and generates intelligent match scores.

The system uses Generative AI, NLP, semantic similarity,
and Retrieval-Augmented Generation (RAG) to evaluate
candidate profiles against job requirements.

## Key Features

- Resume PDF and DOCX parsing
- Semantic similarity matching
- Automated skill gap identification
- Resume-to-job compatibility scoring
- AI-powered resume improvement recommendations

## Technology Stack

- Python
- Flask
- LangChain
- Retrieval-Augmented Generation (RAG)
- Sentence Transformers
- ChromaDB
- NLP

## Project Architecture

Resume Upload → Text Extraction → Embeddings →
Semantic Matching → Scoring → AI Recommendations
